*Most AI code review is a late spec. What human intervention on agent PRs actually consists of.*

When humans intervened on agent-written PRs, here's what the work actually was:

- 58% guidance — restating constraints, enforcing project conventions
- 21% decisions — approve, reject, pick a direction
- 17% fixing the code themselves
- 4% mechanics

Nearly 80% of the effort was telling the agent things it should have known before it started.

The standard only shows up when someone objects to something.

That's specification work done at the most expensive moment possible: after the output exists, after the agent has made ~10 decisions on its own, after someone has to read all of it.

If you keep writing the same review comment, it's not a review comment anymore.

It's a rule. Put it where the work starts.
